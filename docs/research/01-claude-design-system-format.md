## Package layout (all under `project/`)
| path | what |
|---|---|
| `design-system.json` | index; `{"v":3,"layout":"files","createdOnFiles":{"v":1,"at":ISO},"title","namespace","libraries":[],"sections":{},"groups":[],"assetGroups":{},"blobs":{},"docs":{"readme":"project/README.md","sections":[]},"lastChange":{by,at,via,note}}` — written LAST |

## tokens.json shape (NOT DTCG — DTCG maps are unreadable and get dropped)
```json
{"name":"Acme","version":1,
 "color":{"themes":[{"id":"light","name":"Light"},{"id":"dark","name":"Dark"}],
   "tokens":[{"name":"surface-100","value":{"light":"#fbf7f1","dark":"#1d1a17"},"usage":"Page background."}]},
 "type":{"fonts":[{"family":"Acme Sans","file":"fonts/AcmeSans-Regular.woff2","weight":"400"}],
   "families":{"sans":"\"Acme Sans\", system-ui, sans-serif"},
   "groups":[{"name":"Text","family":"sans","styles":[{"name":"body","fontSize":"15px","lineHeight":"22px","fontWeight":400}]}]},
 "spacing":{"tokens":[{"name":"space-4","value":"16px","usage":"Card padding."}]},
 "radius":{"tokens":[{"name":"radius-md","value":"8px","usage":"Buttons, cards."}]}}
```
Rules: names `[A-Za-z0-9][A-Za-z0-9_.-]{0,63}`, unique across families; colors hex/rgb/hsl/oklch or alias `"{other-token}"`;
no named colors, var(), color-mix(); first theme is the fallback; lengths px|rem|em|%; optional `shadow` family same shape.

## Quality checklist from the type
- Usage note on every token; README = brand book with rules naming tokens.
- Contrast 4.5:1 text (3:1 ≥24px, borders, focus rings) in every theme.
- "No AI tropes (blue-purple gradients, emoji cards, left-border cards)."
- Small first system: 6–10 colors, 5–7 text styles, 4 spacing steps, 3 radii.

## Implication for our app
Export targets: (1) this project/ package (zip or direct publish), (2) shadcn CSS vars / registry theme,
(3) optional DTCG JSON, (4) a generated SKILL.md for rules the Design System can't express.
